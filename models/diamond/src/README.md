# DIAMOND source overlay

`inference.py` generates navigation returns, `evaluate_turn.py` handles TURN, and `trainer.py` integrates the LoopNav training data. Shared adaptations live in [data/](data/README.md) and [envs/](envs/README.md). Copy this directory into upstream `src/`; it depends on the remaining upstream source. Follow the [DIAMOND guide](../README.md) for the correct working directory and commands.
